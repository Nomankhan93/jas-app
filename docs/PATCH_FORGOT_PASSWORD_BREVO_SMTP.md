# Patch — Forgot Password with Supabase + Brevo SMTP

## Summary

This patch adds email-based password recovery for the JAS member portal using Supabase Auth. Since custom SMTP is configured in Supabase Cloud with Brevo, reset emails will be sent through the authenticated JAS sender.

## Routes added

- `/forgot-password` — user enters registered email and receives a reset link.
- `/reset-password` — user opens Supabase recovery link and sets a new password.

## Files changed

- `src/routes/login.tsx`
  - Adds “Forgot password?” link for email login.
  - Adds a mobile-login note that email reset works only for email-based accounts.
- `src/routes/forgot-password.tsx`
  - Calls `supabase.auth.resetPasswordForEmail()`.
  - Uses `VITE_PUBLIC_SITE_URL` / `VITE_SITE_URL` / browser origin for redirect URL.
- `src/routes/reset-password.tsx`
  - Detects Supabase recovery session.
  - Calls `supabase.auth.updateUser({ password })`.
  - Signs the user out and redirects back to login after success.
- `src/lib/i18n.tsx`
  - Adds English, Urdu, and Sindhi translations.
- `src/routeTree.gen.ts`
  - Regenerated by TanStack Router so the new routes are registered.

## Supabase Cloud checklist

In Supabase Dashboard → Authentication → URL Configuration, add these redirect URLs:

- `https://jasofficial.org/reset-password`
- `http://localhost:3000/reset-password`

Also confirm:

- Site URL is set to `https://jasofficial.org`.
- Custom SMTP is enabled.
- Sender email is `support@jasofficial.org` or the verified Brevo sender.
- Brevo domain/DNS authentication is passing.

## Local/production env

Production should include:

```env
VITE_PUBLIC_SITE_URL=https://jasofficial.org
VITE_SITE_URL=https://jasofficial.org
```

Local development can use:

```env
VITE_PUBLIC_SITE_URL=http://localhost:3000
VITE_SITE_URL=http://localhost:3000
```

## Test steps

1. Start app: `npm run dev`.
2. Open `/login` and click “Forgot password?”.
3. Enter an email account that exists in Supabase Auth.
4. Check inbox/spam for the Brevo/Supabase reset email.
5. Open the reset link.
6. Set a new password at `/reset-password`.
7. Login again with the new password.

## Notes

Password reset is email-based. Accounts created with only mobile number/password do not have an email inbox for recovery, so those accounts need admin support for password changes.
